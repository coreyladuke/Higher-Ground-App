FREE AI · REAL CONVERSATIONS

Your mountain is already playable offline. For genuine replies, connect your free Cloudflare Worker once. It can run an open-weight model, with a separate second opinion only when an unexpected idea merits a closer look. No paid AI account required for initial testing.

1. Deploy the supplied Worker under your own Cloudflare account, with a Workers AI binding and private access token.
2. Paste the Worker address here, enter the token, and approve sharing only what you type.
3. Tap Test AI connection and wait for a reply from the real model.

For early testing only. Cloudflare and optional Groq receive your submitted words. Do not enter sensitive personal information. Free quotas are limited and can change.

Only you control this token. Set the same value as the HG_ACCESS_TOKEN secret in Cloudflare. Don't publish it or send it in a screenshot.

These credentials and consent are never saved in your app progress, history, or exports. The Cloudflare Worker holds any provider API keys. This is a founder-only test, not a secure multi-user login.

Open-weight SmolLM2-360M-Instruct runs locally using Transformers.js/WebGPU. First launch may download ~280 MB. Small models can misunderstand context or provide weak feedback. Requires compatible browser/GPU and network to download model once.
Calls Google's generative language API directly for this private development test. Data you send goes to Google. Free-tier eligibility, quota, and terms vary; production needs a secured backend.

For Ollama or other local services, your browser must be allowed to reach the service (CORS). Never publish a browser app with an embedded secret.

On-device AI is not loaded yet.
